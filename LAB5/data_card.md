# Data card

The dataset is generated by sklearn.datasets.make_moons with 200 samples, noise 0.15 and random_state 42. Each example has two real-valued coordinates and a binary class. The 70/30 train/test split is stratified with random_state 42. There are 140 training and 60 test examples. This synthetic benchmark has no personal data and illustrates nonlinear classification. Its accuracy does not establish performance on real-world datasets.
