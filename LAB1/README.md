# ML Systems — Lab 01

Environment setup, baseline models, system measurements, and deployment suitability analysis.

## Project structure

- `src/` — source code (`run_lab.py`, `print_versions.py`).
- `results/` — generated model files and CSV measurements.
- `report.md` — laboratory report.

## Setup and run

From the `LAB1` folder:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/print_versions.py
python src/run_lab.py
```

The script writes `baseline_accuracy.csv`, `measurements.csv`, `deployment_fit.csv`, and two `.joblib` models to `results/`. Results are machine-dependent and must be generated by running the code.
